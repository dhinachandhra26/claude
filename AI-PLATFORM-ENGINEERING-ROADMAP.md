# AI Platform Engineering — 12-Month Career Roadmap

**Timeline:** November 2026 – October 2027  
**Study commitment:** 8–10 hours per week  
**Career goal:** Senior AI Platform Engineer; long-term Staff Engineer / AI Platform Architect.

## Current strengths

- TypeScript, JavaScript, Node.js, REST, GraphQL, microservices
- Distributed systems, BullMQ, event pipelines, distributed locking
- Redis, MongoDB, PostgreSQL
- Docker, Kubernetes, Helm, NGINX, Terraform, Ansible
- Logging, metrics, reliability and performance engineering

## Monthly roadmap

### Phase 1 — AI and programming foundations (November 2026 – January 2027)

- [ ] **Nov 2026 — Claude + MCP:** Study Claude API, prompt engineering, structured outputs, tool calling, MCP and agents. **Build:** a TypeScript Claude assistant with three read-only tools. **Milestone:** complete the CCAR-F Udemy course.
- [ ] **Dec 2026 — Python:** Learn Python, asyncio, FastAPI, Pydantic and pytest. **Build:** a tested diagnostic API deployed to Kubernetes.
- [ ] **Jan 2027 — Production agents:** Learn orchestration, tool permissions, tracing, context handling, evaluation and retries. **Build:** a read-only Kubernetes and Prometheus incident-investigation assistant.

### Phase 2 — Advanced platform engineering (February – April 2027)

- [ ] **Feb 2027 — AWS architecture:** Learn VPC, IAM, EC2, EKS, ALB, S3, cloud networking and cost controls. **Build:** a Terraform-managed cloud deployment.
- [ ] **Mar 2027 — GitOps and developer platform:** Learn Argo CD, Helm, GitHub Actions, secrets management and self-service. **Build:** a GitOps pipeline with rollback.
- [ ] **Apr 2027 — Go and Kubernetes controllers:** Learn Go concurrency, client-go, CRDs, reconciliation and controller patterns. **Build:** a minimal custom Kubernetes controller in a lab.

### Phase 3 — AI infrastructure and LLMOps (May – July 2027)

- [ ] **May 2027 — LLM inference:** Learn tokenization, embeddings, batching, vLLM and OpenAI-compatible APIs. **Build:** host an open-weight model and benchmark latency/throughput.
- [ ] **Jun 2027 — Kubernetes inference platform:** Learn GPU scheduling, device plugins, resource isolation, storage and autoscaling. **Build:** model-serving deployment with load tests and resource reporting.
- [ ] **Jul 2027 — LLMOps:** Learn OpenTelemetry, Prometheus, model evaluations, secrets, audit logs, RBAC and incident alerts. **Build:** secured, observable inference platform.

### Phase 4 — Architecture and career transition (August – October 2027)

- [ ] **Aug 2027 — Internal AI developer platform:** Learn platform APIs, developer self-service, tenant isolation, quotas and cost attribution. **Build:** a deployment template/workflow for AI services.
- [ ] **Sep 2027 — System architecture:** Learn HA, DR, SLOs, capacity planning, incident response, security and cost efficiency. **Build:** architecture decision records and failure test results.
- [ ] **Oct 2027 — Portfolio and interviews:** Practice senior/staff system design and architecture communication. **Build:** polished GitHub projects, resume case studies and interview narratives.
